# AI前沿雷达 · GitHub Pages

免费静态阅读站。沿用已认可的白黑蓝界面；共享公开研究内容，收藏、已读和备注仅保存在当前浏览器，不上传、不跨设备同步。浏览器记录可自行导出或清除，不会影响其他人。

这是公开网站，不提供账号、邀请制访问或数据库服务，不收集姓名、邮箱、手机号和用户上传，不安装第三方统计。浏览器请求由GitHub托管处理，GitHub会按其政策记录访问IP；见[GitHub Pages说明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)。

GitHub Actions定时检查11个公开入口并发布静态数据，每4小时、每日北京时间09:00和周五18:00更新，可能延迟。新发现只进待精读题录；全文、主要图表、核心附录和证据未核查时不会成为正式介绍。

此免费工作流不调用模型，不读取模型密钥，不产生模型调用费用。已有3份经过核查的公开研究档案，其中1份基础论文全文精读、2份官方原始技术材料。模型自动精读仍未接入；不得把来源抓取或构建成功称为完成精读。

所有静态资源和JSON使用相对路径，支持GitHub项目子路径与查询参数深链接。源码和cloud-data仅包含公开研究数据；原私有研究仓库、身份、环境和本机数据库不在此仓库。

## 构建

Node24；`npm ci`，`npm test`，`npm run build`。产物位于dist/。修改研究档案先通过lib/research.ts质量校验，再由scripts/public-data.ts按字段白名单投影；不得直接把任意数据库导出到public/。

GitHub Pages可免费用于公共仓库；Pages网站本身公开可访问。实际国内网络可达性需由读者测试，不承诺所有网络或地区始终可达。独立域名可选，此版本无需购买域名或云服务器。
