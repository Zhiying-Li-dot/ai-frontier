# AI 前沿主题观察台

用户希望借鉴 AISafetyHot 提升本站，并将更新发布到现有 GitHub Pages。

本轮交付独立设计的主题观察台、主题与时间组合筛选、可继续加载的候选列表。观察台只统计当前公开快照，已核查档案与待精读题录分别计数。主题根据标题和标签关键词匹配，允许多主题；未匹配内容保留在“其他研究”。时间图按上海日期显示最近 7 天的原文发表数量，不称全网热度、质量评分或趋势预测。相同来源去重，已核查记录优先；未来和无效日期不计入近期统计。主题图位置只是导航排布，不推断论文关系。

维持原有阅读、证据、收藏和本地工作台功能。桌面展示主题图与活动条形图，手机展示可读的主题按钮。支持键盘、明确焦点、减少动态效果偏好。所有新界面使用本站数据和原创代码，不复制参考站的内容或视觉资产。不增加模型调用、付费服务或个人数据上传。

验收：统计与筛选边界的单元测试；浏览器验证主题筛选、加载更多、搜索后重置、直达阅读和移动端溢出；完整现有测试与构建；最终代码审查；部署后验证实际网站与档案数据。
